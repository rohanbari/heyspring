# Contributing to heyspring

Thanks for your interest in contributing.

## How to contribute

1. Fork the repository and create a feature branch.
2. Keep changes focused and small.
3. Add or update tests where relevant.
4. Run checks locally:
   - `./gradlew test`
5. Open a pull request with:
   - clear summary of the problem
   - explanation of your solution
   - any testing notes

## Development notes

- Java version: 21
- Build tool: Gradle
- Main API base path: `/api/tasks`

## Code style

- Prefer clear, readable code.
- Follow existing project structure and naming patterns.
- Avoid unrelated refactors in the same pull request.
