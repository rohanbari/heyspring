# Security Policy

## Supported versions

Security updates are currently provided for the latest code on the default branch.

## Reporting a vulnerability

Please do not open public issues for security vulnerabilities.

Instead:

1. Report privately to repository maintainers.
2. Include reproduction steps, affected endpoints, and impact.
3. Provide any suggested mitigation if available.

We will acknowledge the report and work on validation and remediation as quickly as possible.
